Full-Spectrum Domain Diagnostic & Security Auditor

Evaluate authoritative DNS delegation health, RFC 2308 negative cache staleness, email deliverability posture, and infrastructure drift in seconds.

# Quick Install via Homebrew: brew tap smford/tap && brew install domain-doctor

Core Capabilities

RFC 2308 Negative Caching

Detect when public Anycast resolvers (1.1.1.1, 8.8.8.8, 9.9.9.9) serve stale NXDOMAIN or NODATA caches while authoritative servers serve live records. Computes exact eviction countdowns.

Mail Authentication Audit

Recursively counts SPF DNS lookups against the 10-mechanism RFC 7208 PermError ceiling. Validates DMARC p=reject alignment, scans common DKIM selectors, and probes port 25 STARTTLS.

Subdomain Takeover Defense

Checks dangling CNAME records against known cloud signature patterns (AWS S3, CloudFront, GitHub Pages, Heroku, Azure) returning unclaimed NXDOMAIN statuses.

BGP & Resilience Mapping

Resolves authoritative nameserver IPs to origin BGP Autonomous Systems via Team Cymru DNS without rate-limited external APIs, exposing single points of failure.

Live Cutover Watch Mode

Interactive Bubble Tea TUI dashboard providing real-time tracking of SOA serial bumps, record transitions, and negative cache evictions during live domain migrations.

IaC Drift & Export

Audits out-of-band record drift directly against local terraform.tfstate files, and exports discovered zone configurations to standard RFC 1035 BIND or Route53 HCL.

CLI Command Reference

Command Description
domain-doctor scan <domain> Full diagnostic domain scan with color-coded severity badges (--json, --tui, --mermaid)
domain-doctor watch <domain> Continuous polling TUI dashboard for tracking live DNS cutovers (--interval=3s)
domain-doctor snapshot <domain> Save current zone records and diagnostic findings to structured JSON
domain-doctor diff <file.json> <domain> Compare a captured snapshot against live DNS to verify migration integrity
domain-doctor lint <domain> Headless CI/CD audit with exit codes (0 clean, 1 critical, 2 warning) and SARIF export
domain-doctor diagram <domain> Output clean Mermaid definitions (--type=delegation|spf|mail)
domain-doctor export <domain> Reverse-engineer active DNS records into RFC 1035 BIND or Terraform Route53 HCL
domain-doctor audit-drift <domain> Compare declared Route53/Cloudflare resources in terraform.tfstate against live DNS
